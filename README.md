
# CareerLab

### Descubra seu potencial. Explore seu futuro.

## Sobre o projeto

O CareerLab é uma plataforma digital de orientação profissional desenvolvida com o objetivo de ajudar jovens a conhecer diferentes profissões, explorar seus interesses e descobrir possibilidades para o futuro.

A plataforma busca tornar a exploração de carreiras mais acessível, interativa e organizada.

## Objetivos

- Incentivar o autoconhecimento.
- Apresentar diferentes áreas profissionais.
- Explorar possibilidades de carreira.
- Auxiliar na reflexão sobre escolhas profissionais.

## Funcionalidades

- Página inicial informativa.
- Navegação entre seções.
- Seletor de idiomas.
- Apresentação de áreas profissionais.
- Teste interativo de interesses (em desenvolvimento).
